📚 আজকের পাঠ — ধাপ ১

১. কেন শিখছি

HTML দিয়ে অ্যাপের কাঠামো, CSS দিয়ে সৌন্দর্য এবং JavaScript দিয়ে অ্যাপের কাজ নিয়ন্ত্রণ করা হয়।

২. ছোট ব্যাখ্যা

HTML হলো অ্যাপের শরীর। CSS হলো অ্যাপের ডিজাইন। JavaScript হলো অ্যাপের বুদ্ধি।

৩. উদাহরণ

HTML দিয়ে একটি বোতাম বানানো যায়। CSS দিয়ে বোতামের রং পরিবর্তন করা যায়। JavaScript দিয়ে বোতামে চাপলে বার্তা দেখানো যায়।

৪. নিজের হাতে লেখার কাজ

HTML ট্যাবে একটি নতুন h2 ট্যাগ যোগ করো। তার মধ্যে নিজের পছন্দের অ্যাপের নাম লেখো।

৫. ইঙ্গিত

h2 ট্যাগ লেখার নিয়ম: <h2>আমার অ্যাপ</h2>
